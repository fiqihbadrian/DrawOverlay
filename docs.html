Panduan Stellaire DrawOverlay

Semua yang perlu Anda ketahui untuk menggunakan DrawOverlay — dari izin pertama hingga menyimpan hasil gambar.

Daftar Isi

Persyaratan Instalasi Izin yang Dibutuhkan Ikon Overlay Menggambar Quick Menu Mode Kanvas Kotak Kanvas & Layer Menyimpan PNG Mode Matematika Setelan Pemecahan Masalah

1. Persyaratan Sistem

PlatformAndroid
Versi minimalAndroid 10 (API 29)
Koneksi internetTidak diperlukan (semua proses on-device)
Akun / loginTidak diperlukan

2. Instalasi

  1. Unduh file .apk dari halaman Releases.
  2. Buka file tersebut di HP Android Anda.
  3. Jika muncul peringatan "instal dari sumber tidak dikenal", izinkan (biasanya di Setelan → Keamanan → Instal aplikasi tidak dikenal).
  4. Buka aplikasi Stellaire DrawOverlay.

3. Izin yang Dibutuhkan

DrawOverlay membutuhkan beberapa izin agar bisa menggambar di atas aplikasi lain. Semua izin hanya digunakan untuk fitur yang Anda aktifkan.

IzinKegunaan
OverlayMenampilkan ikon melayang & kanvas transparan di atas aplikasi lain (wajib).
NotifikasiMenampilkan notifikasi "overlay aktif" (Android 13+).
PenyimpananMenyimpan PNG ke galeri Anda (Pictures/DrawOverlay).
Izin LayarOpsional — untuk menyertakan tampilan layar saat menyimpan PNG (MediaProjection).
Catatan: semua izin dapat dicabut kapan saja lewat Setelan Android. Tanpa izin Overlay, aplikasi tidak dapat menggambar di atas aplikasi lain.

4. Ikon Overlay (Floating Button)

Setelah menekan Start Overlay, sebuah ikon bulat muncul di pojok layar. Ikon ini selalu tersedia selama overlay aktif.

  • Ketuk — membuka/menutup quick menu dan mengaktifkan kanvas untuk menggambar.
  • Tarik — memindahkan ikon ke posisi lain di layar.

5. Menggambar

Setelah kanvas aktif, semua sentuhan di layar digunakan untuk menggambar. Toolbar menyediakan:

  • Pen / Brush — goresan halus dengan interpolasi bezier & spline Catmull-Rom.
  • Penghapus — menghapus sebagian goresan.
  • Ukuran — mengatur ketebalan pena/penghapus.
  • Warna — preset, hex kustom, dan mode pelangi.
  • Undo / Redo — membatalkan / mengulang goresan.
  • Bersihkan — menghapus seluruh isi kanvas (masih bisa di-undo).

6. Quick Menu

Ketuk ikon overlay untuk membuka quick menu berisi aksi cepat:

  • Kanvas — aktifkan/nonaktifkan kanvas menggambar.
  • Pen, Penghapus, Ukuran, Warna — pintasan alat gambar.
  • Undo / Redo / Bersihkan — manajemen goresan.
  • Simpan — simpan PNG ke galeri.
  • Tembus — sentuhan diteruskan ke aplikasi belakang.
  • Hentikan — menutup overlay sepenuhnya.

7. Mode Kanvas

DrawOverlay memiliki tiga mode utama:

  • Mode Menggambar (Drawing Mode) — kanvas aktif, semua sentuhan untuk menggambar.
  • Mode Tembus (Touch-Through) — kanvas tetap terlihat tetapi sentuhan diteruskan ke aplikasi di belakang.
  • Mode Tersembunyi (Hidden) — kanvas disembunyikan; ikon overlay tetap tampil untuk diaktifkan kembali.

8. Kotak Kanvas & Layer

  • Kotak Kanvas — buat area kanvas kecil terpisah untuk menggambar di satu bagian layar, atau hapus kotak yang tidak dipakai.
  • Layer — tambah, tampilkan, atau sembunyikan layer; goresan tiap layer dapat dihapus tanpa memengaruhi layer lain.

9. Menyimpan PNG

Tekan Simpan untuk menyimpan gambar sebagai PNG ke galeri (Pictures/DrawOverlay). Ada dua perilaku:

  • PNG transparan — hanya goresan Anda dengan latar transparan.
  • PNG dengan latar layar — menyertakan screenshot layar di belakang goresan (membutuhkan izin layar / MediaProjection).
Catatan: tanpa izin layar, penyimpanan hanya berisi goresan di kanvas — bukan screenshot layar. Untuk menyertakan tampilan layar, gunakan izin layar atau fitur screenshot bawaan HP Anda.

10. Mode Matematika (Beta)

Mode Matematika mengenali tulisan tangan Anda langsung di perangkat (pengenalan digital ink ML Kit on-device) lalu mengevaluasi ekspresinya. Tidak ada data yang dikirim ke internet — semuanya diproses lokal. Dukung pengenalan simbol dengan mengoreksi hasil lewat dialog pilihan simbol; koreksi Anda disimpan untuk belajar.

Status: Mode Matematika masih dalam pengembangan dan penyempurnaan.

11. Setelan

  • Bahasa — Bahasa Indonesia atau English (otomatis mengikuti bahasa sistem, bisa diubah manual).
  • Opasitas menu — transparansi panel menu saat ikon overlay diketuk (0% = transparan penuh).
  • Informasi aplikasi — nama, versi, dan deskripsi singkat.
  • Kebijakan — tautan ke Kebijakan Privasi.

12. Pemecahan Masalah

Kanvas tidak muncul setelah menekan Start Overlay

Pastikan izin Overlay sudah diizinkan di Setelan Android. Tanpa izin ini, ikon dan kanvas tidak akan tampil.

Gambar yang disimpan tidak menyertakan layar

Simpan tanpa izin layar hanya berisi goresan. Berikan Izin Layar di beranda, atau gunakan screenshot bawaan HP.

Sentuhan tidak merespons di aplikasi lain

Kanvas sedang dalam Mode Menggambar. Matikan kanvas atau aktifkan mode Tembus agar sentuhan diteruskan ke aplikasi belakang.
